Auracle Desktop — bundled type: licences and provenance
=======================================================

The launcher ships three typefaces inside the application binary. Nothing is
fetched at runtime: there is no CDN link, no Google Fonts request, no network
access of any kind involved in rendering text. The woff2 files are pulled from
the npm packages listed below at build time and emitted into the app bundle by
Vite, so every platform target (dmg / msi / deb / rpm / appimage) renders the
same faces, offline, on first paint.

All three faces are licensed under the SIL Open Font License, Version 1.1
(OFL-1.1) — a permissive licence that allows bundling inside a commercial,
closed-source application. The one obligation that touches us: the fonts may
not be sold on their own, and this notice must travel with the software.
Full licence text: http://scripts.sil.org/OFL

-----

   https://github.com/undercasetype/Fraunces

   Variable axes shipped: wght 100–900, opsz 9–144. SOFT and WONK are fixed

3. JetBrains Mono  ·  role: data mono  ·  OFL-1.1
   Copyright 2020 The JetBrains Mono Project Authors

Subsetting
----------

Only the **latin** subset of each face is bundled. The fontsource packages'
own CSS entrypoints also declare latin-ext and vietnamese cuts; importing them
would roughly triple the on-disk cost for glyph ranges this UI has no copy
for. So `src/styles/app.css` declares the @font-face rules by hand and points
them at the specific latin woff2 files inside those packages — the packages
stay the source of truth for provenance and updates, while the bundle carries
only what renders.

Total bundled type: ~155 KB across four woff2 files (design budget: 350 KB).

The @fontsource packages themselves are MIT-licensed tooling; the font files
they redistribute carry the OFL-1.1 terms above. Per-face licence texts ship
verbatim in node_modules/<package>/LICENSE.

Third-party code vendored into the app
--------------------------------------

Type is not the only thing bundled from outside. One source file in `src/` is
an adapted copy of someone else's work rather than a dependency, and carries
its own terms:

1. src/fx/DotField.tsx  ·  the ambient dot-field behind the home and sign-in
   Adapted from react-bits, Copyright (c) 2026 David Haz
   https://github.com/DavidHDev/react-bits
   Upstream path: src/ts-default/Backgrounds/DotField/DotField.tsx (@ c7109dc)
   Licence: MIT + Commons Clause License Condition v1.0

   The MIT grant is extended to cover use, modification and distribution
   "as part of an application, website, or product", which is what this is.
   The Commons Clause bars one thing: selling, sublicensing or redistributing
   **the components themselves** — alone, bundled, or ported. Auracle sells a
   trading platform, not a component library, so the condition is satisfied by
   never publishing this file as a package or as part of one. The copyright
   notice and licence line travel in the file's own header, as the licence
   requires.

   Adapted substantially: retyped, ink re-pointed at the house --stage-dot
   tokens, sparkle / cursor-glow / gradient layers removed, geometry pinned to
   the launcher's performance budget, and the render loop put under the
   visibility/focus power law in src/fx/ambient.ts.

GSAP (the motion engine, src/fx/motion.ts) is a normal dependency rather than
vendored code, and ships under the GreenSock standard "no charge" licence —
free inside a commercial product, barred only from being resold as a tool.
@gsap/react is MIT.
